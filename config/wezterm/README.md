WezTerm uses the opaque `#1e2030` color from `wezterm.lua` as its terminal
background. Files in `backgrounds/` are retained as optional assets and are not
loaded automatically.

The terminal font is JetBrains Mono Medium with Symbols Nerd Font Mono as the
icon fallback. Both fonts are bundled with WezTerm, so this setup stays portable
across macOS and Linux. On macOS, Hiragino Sans GB provides complete Simplified
Chinese coverage; other platforms continue to use their system CJK fallback.
